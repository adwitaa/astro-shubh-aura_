# Astro Shubh Aura
Welcome to the Astro Shubh Aura project repository. This web application provides astrological services and religious products. It is designed with a traditional desi aesthetic featuring yellow backgrounds, red text, and engaging animations.

Technologies Used
TanStack Start: Full stack framework leveraging React for building the application.
React 19: Core library for building interactive user interfaces.
Vite: Fast build tool and development server.
Tailwind CSS: Utility class framework used for all styling and layout needs.
Radix UI: Unstyled, accessible component primitives.
React Hook Form: Library for managing forms and handling user input efficiently.
Zod: Schema validation for forms and server requests.
Recharts: Charting library for data visualization.
Embla Carousel: Used for creating smooth sliders and image carousels.
Lucide React: Clean and beautiful icon library.
TypeScript: Programming language providing strict type safety across the codebase.
ESLint and Prettier: Tools for maintaining code quality and consistent formatting.

Features Implemented
Landing Page: The main entry point introducing the platform with animated sections and traditional styling.
Kundali Interface: A dedicated section for astrological charts, complete with a functional Kundali enquiry submission form connecting to the backend.
Astro Consultancy: A page providing details and booking capabilities for astrological consultation services.
Pooja Samagri Store: A product catalog displaying religious items such as Havan samagri, Guggal, Lobaan, Kapoor, Chandan powder, Haldi, Kumkum, Akshat, Jau, Panchmeva, Panchratna, and Navadhanya.
Backend Integration: Server functions handling API requests like form submissions securely.
Multi language Architecture: Foundation laid for translating the application into different languages.
Responsive Design: Fluid layouts that adapt perfectly to both mobile devices and desktop screens.
